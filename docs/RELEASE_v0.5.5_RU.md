# Flipper Dongle v0.5.5 — первая тестовая версия

Это первая тестовая веха Flipper Dongle, которую можно считать рабочей базой для дальнейшей проверки.

## Работает
- клавиатура Flipper Bluetooth Remote
- мышь Flipper Bluetooth Remote
- BadUSB / BadKB по BLE
- мост BLE HID -> ESP32-S3 -> USB HID
- press/release клавиатуры без залипания
- синхронизация USB HID через callback завершения TinyUSB
- несколько HID bond-профилей, до 4 сопряжений
- CDC-консоль для отладки

## Важно
Bluetooth Remote и BadUSB/BadKB могут определяться как разные BLE-устройства и могут требовать отдельного сопряжения.

## Известные ограничения
- кнопка pairing/reset ещё требует многократной проверки пограничных сценариев
- в тестовой сборке пока присутствует CDC COM-порт
- переключатель HID/DRIVE и USB MSC для microSD ещё не объединены с этой веткой
- интерфейс на LCD ещё не реализован

## Проверенное железо
Waveshare ESP32-S3-LCD-1.47

## Статус
Первая тестовая версия / проверенная рабочая база.
