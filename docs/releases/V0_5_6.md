# Flipper Dongle v0.5.6

Three full ESP32-S3 images are provided, one per board. Each is written at
`0x0` and includes its own bootloader, partition table, and application. A
full-image flash clears saved BLE bonds. Keep a backup of the factory flash
before installing firmware on a new board.

| Board | File | Flash configuration | Check |
| --- | --- | --- | --- |
| Pocket-Dongle-S3-0.96 clone | `Flipper-Dongle-v0.5.6-Pocket-S3-0.96.bin` | 16 MB | Pocket BLE HID, screen, BOOT pairing/reset and displayed pairing digits checked on hardware |
| Waveshare ESP32-S3-LCD-1.47 | `Flipper-Dongle-v0.5.6-Waveshare-ESP32-S3-LCD-1.47.bin` | 2 MB build configuration | Build checked; BLE HID baseline was checked on hardware before this release |
| Original LILYGO T-Dongle-S3 | `Flipper-Dongle-v0.5.6-LILYGO-T-Dongle-S3.bin` | 16 MB | Build checked; no LILYGO hardware test yet |

The LILYGO image is for the **original T-Dongle-S3** only. It uses the
manufacturer's published display pins and is not suitable for the Pocket clone,
T-Dongle-S2, T-Dongle-S3-Dual, or T-Dongle-S3-Plus. See
[`docs/hardware/LILYGO_T_DONGLE_S3.md`](../hardware/LILYGO_T_DONGLE_S3.md).

## Flashing

Enter the ESP32-S3 bootloader with BOOT held while connecting USB. Replace
`COM_PORT` with the loader port, and replace `FILE.bin` with the exact binary
for your board:

```powershell
python -m esptool --chip esp32s3 -p COM_PORT write-flash 0x0 .\FILE.bin
```

After `Hash of data verified`, reconnect without holding BOOT. The current
build exposes USB keyboard, mouse, and CDC COM for debug logs. Short BOOT starts
one BLE scan; long BOOT clears the stored HID bonds. Pocket has no HID/DRIVE
switch, and microSD/DRIVE mode is not in this release.

## Changes

- Fix pairing/reset races after bond deletion and rapid short-BOOT presses.
- Show the real BLE numeric-comparison code on the Pocket/LILYGO dolphin
  placard until encryption completes or the link disconnects.
- Keep the BLE HID-to-USB HID keyboard/mouse transport and BadUSB support.
- Add a separate original LILYGO board profile without changing Pocket pins.
