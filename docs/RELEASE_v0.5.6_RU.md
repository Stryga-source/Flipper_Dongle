# Flipper Dongle v0.5.6 — тестовый кандидат

**Статус: ожидает проверки.**

v0.5.6 основана на v0.5.5 и меняет только логику состояния pairing/reset. Рабочие клавиатура, мышь и USB HID-транспорт намеренно не изменялись.

## Исправляемая проблема
После очистки BLE-сопряжений длинным BOOT следующее короткое нажатие BOOT иногда было видно в serial-логе, но поиск для сопряжения не запускался.

Проблема проявлялась не всегда, потому что:
- BLE disconnect выполняется асинхронно
- поздний `ESP_HIDH_CLOSE_EVENT` мог стереть новый запрос pairing
- блокирующий BLE scan мог вернуть устаревший результат уже после очистки bond

## Изменения
- явная синхронизация состояния pairing/reset
- отложенный pairing, если short BOOT нажат во время завершения disconnect
- счётчик поколения BLE scan
- устаревший scan после reset отбрасывается
- старый scan не может снова подключить устройство после удаления bond
- рабочий HID-транспорт v0.5.5 не изменён

## Что нужно проверить
Несколько раз повторить:
1. подключить Bluetooth Remote или BadUSB
2. длинный BOOT для очистки bond
3. сразу короткий BOOT
4. повторить с задержкой 1–2 секунды
5. повторить, когда HID-профиль Flipper уже рекламируется

Ожидаемый результат: каждое короткое нажатие BOOT либо сразу запускает scan, либо запоминается и запускается после завершения disconnect.

## Статус
Test candidate — не считать основной версией до повторной проверки на реальном железе.
